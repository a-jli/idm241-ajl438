IDM 241: Beta Description

Itch.io

Interaction: Game Card

Triggers

Game Card Thumbnail

  • Hover ON
  • Hover OFF

Add to Collection Button

  • Hover ON
  • Hover OFF
  • Mouse DOWN
  • Mouse UP

Game Page Preview

  • Hover ON
  • Hover OFF

Rules

Game Card Thumbnail

  • Hover ON
    • Cursor changes from Default to Pointer
    • Add to Collection button increases opacity from 0% to 100% over 0.2s
    • Add to Collection button slides down 4px over 0.2s
    • 0.4s Delay
      • Game Page Preview increases opacity from 0% to 100% over 0.2s
      • Game Page Preview slides down to halfway down card image over 0.2s
      • Game Page Preview Images pull up from bottom over 0.2s
  • Hover OFF
    • Cursor changes from Pointer to Default
    • Add to Collection button decreases opacity from 100% to 0% over 0.2s
    • Add to Collection button slides up 4px over 0.2s
    • 0.4s Delay
      • Game Page Preview decreases opacity from 0% to 100% over 0.2s
      • Game Page Preview slides down from halfway down card image over 0.2s

Add to Collection Button

  • Hover ON
    • Cursor changes from Default to Pointer
    • Border changes from RED to PINK over 0.2s
    • Fill changes from DARKER GREY to DARK GREY over 0.2s
  • Hover OFF
    • Cursor changes from Pointer to Default
    • Border changes from PINK to RED over 0.2s
    • Fill changes from DARK GREY to DARKER GREY over 0.2s
  • Mouse DOWN
    • Button shrinks by 0.9 over 0.2s
  • Mouse UP
    • Button reverts to original size over 0.2s
    • "Add to collection" modal opens
      • GREY fill overlays window under modal over 0.12s
      • Overlay increases opacity from 0% to 80% over 0.12s

Game Page Preview

  • Hover ON
    • Cursor changes from Default to Pointer
    • Fill changes from DARK GREY to GREY over 0.2s
  • Hover OFF
    • Cursor changes from Pointer to Default
    • Fill changes from GREY to DARK GREY over 0.2s
