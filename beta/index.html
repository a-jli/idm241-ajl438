Interaction: Game Card

Triggers

Game Card

  • Hover ON
    • 0.4s Delay
  • Hover OFF
    • 0.4s Delay

Add to Collection Button

  • Hover ON
  • Hover OFF
  • Mouse DOWN
  • Mouse UP

Game Page Preview Popup

  • Hover ON
  • Hover OFF

Rules

Game Card

  • Hover ON
    • Cursor changes from Default to Pointer
    • 0.4s Delay
      • Game Page Preview Popup increases opacity from 0% to 100% over 0.2s
      • Game Page Preview Popup slides down to halfway down card image over 0.2s
      • Game Page Preview Popup Images pull up from bottom over 0.2s
  • Hover OFF
    • Cursor changes from Pointer to Default
    • 0.4s Delay
      • Game Page Preview Popup decreases opacity from 0% to 100% over 0.2s
      • Game Page Preview Popup slides down from halfway down card image over 0.2s

Add to Collection Button

  • Hover ON
    • Cursor changes from Default to Pointer
    • Border changes from RED to PINK
    • Fill changes from DARKER GREY to DARK GREY
  • Hover OFF
    • Cursor changes from Pointer to Default
    • Border changes from PINK to RED
    • Fill changes from DARK GREY to DARKER GREY
  • Mouse DOWN
    • Button shrinks by 0.9 over 0.2s
  • Mouse UP
    • Button reverts to original size over 0.2s

Game Page Preview Popup

  • Hover ON
    • Cursor changes from Default to Pointer
    • Fill changes from DARK GREY to GREY
  • Hover OFF
    • Cursor changes from Pointer to Default
    • Fill changes from GREY to DARK GREY
