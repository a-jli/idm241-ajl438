IDM 241: Alpha Description

Itch.io

Interaction: Rating Star Icons

After logging in, click onto any game to navigate to its page, then click the "Rate this game" button on the top right to pull up the "Rate & Review" window.

Triggers

Star Icon

  • Hover ON
  • Hover OFF
  • Click ON

Rules

Star Icons Default - No Stars Selected

  • Hover ON
    • Cursor changes from Default to Pointer
    • Star fill changes from WHITE to DARK GREY
    • Star outline changes from GREY to DARK GREY
  • Hover OFF
    • Cursor changes from Pointer to Default
    • Star fill changes from DARK GREY to WHITE
    • Star outline changes from DARK GREY to GREY
  • Click Toggle ON
    • Star fill changes from DARK GREY to RED
    • Star outline changes from GREY to RED

Star Icons Default - Any Star Selected

  • Hover ON
    • Cursor changes from Default to Pointer
    • Star fill changes from WHITE to RED
    • Star outline changes from GREY to RED
  • Hover OFF
    • Cursor changes from Pointer to Default
    • Star fill changes from RED to WHITE
    • Star outline changes from RED to GREY
  • Click Toggle ON
    • Star fill stays RED
    • Star outline stays RED

Star Icons - Left of Hovered Star:

  • Hover ON
    • Star fill changes from WHITE to DARK GREY
    • Star outline changes from GREY to DARK GREY
  • Hover OFF
    • Star fill changes from DARK GREY to WHITE
    • Star outline changes from DARK GREY to GREY
  • Click Toggle ON
    • Star fill changes to/stays RED, ignoring Hover OFF
    • Star outline changes to/stays RED, ignoring Hover OFF

Star Icons - Right of Hovered Star:

  • Hover ON
    • Star fill changes to WHITE
    • Star outline changes to GREY
  • Hover OFF - No Star to Right Selected
    • N/A
  • Hover OFF - Any Star to Right Selected
    • Star fill changes to RED
    • Star outline changes to RED
  • Click Toggle ON
    • Star fill stays WHITE, ignoring Hover OFF
    • Star outline stays GREY, ignoring Hover OFF
