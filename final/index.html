  • Hover OFF

Rules

Game Card Thumbnail

  • Hover ON
    • Cursor changes from Default to Pointer
    • Add to Collection button increases opacity from 0% to 100% over 0.2s
    • Add to Collection button slides down 4px over 0.2s
    • 0.4s Delay
      • Game Page Preview increases opacity from 0% to 100% over 0.2s
      • Game Page Preview slides down to halfway down card image over 0.2s
      • Game Page Preview Images pull up from bottom over 0.2s
  • Hover OFF
    • Cursor changes from Pointer to Default
    • Add to Collection button decreases opacity from 100% to 0% over 0.2s
    • Add to Collection button slides up 4px over 0.2s
    • 0.4s Delay
      • Game Page Preview decreases opacity from 0% to 100% over 0.2s
      • Game Page Preview slides up from halfway down card image over 0.2s

Add to Collection Button

  • Hover ON
    • Cursor changes from Default to Pointer
    • Border changes from RED to PINK over 0.2s
    • Fill changes from DARKER GREY to DARK GREY over 0.2s
  • Hover OFF
    • Cursor changes from Pointer to Default
    • Border changes from PINK to RED over 0.2s
    • Fill changes from DARK GREY to DARKER GREY over 0.2s
  • Mouse DOWN
    • Button slides down 2px over 0.2s
  • Mouse UP
    • Button slides UP 2px over 0.2s
    • "Add to collection" modal opens
      • GREY fill overlays window under modal over 0.12s
      • Overlay increases opacity from 0% to 60% over 0.12s

Game Page Preview

  • Hover ON
    • Cursor changes from Default to Pointer
    • Fill changes from DARK GREY to GREY over 0.2s
  • Hover OFF
    • Cursor changes from Pointer to Default
    • Fill changes from GREY to DARK GREY over 0.2s

More Like This Button

  • Hover ON
    • Cursor changes from Default to Pointer
    • Fill changes from GREY to LIGHTER GREY over 0.2s
  • Hover OFF
    • Cursor changes from Pointer to Default
    • Fill changes from GREY to LIGHTER GREY over 0.2s
  • Click ON
    • Button slides down 2px over 0.2s
  • Click OFF
    • Button slides UP 2px over 0.2s

Rating Stars

  • Hover ON
    • Tooltip opacity increases from 0% to 100% over 0.2s
  • Hover ON
    • Tooltip opacity decreases from 0% to 100% over 0.2s
  • Click ON
    • GREY fill overlays window under modal over 0.12s
    • Overlay increases opacity from 0% to 60% over 0.12s
    • Rate & Review Modal overlays GREY fill

Star Icons Default - Any Star Selected

  • Hover ON
    • Cursor changes from Default to Pointer
    • Star fill changes from WHITE to RED over 0.2s
    • Star outline changes from GREY to RED over 0.2s
  • Hover OFF
    • Cursor changes from Pointer to Default
    • Star fill changes from RED to WHITE over 0.2s
    • Star outline changes from RED to GREY over 0.2s
  • Click Toggle ON
    • Star fill stays RED
    • Star outline stays RED

Star Icons - Left of Hovered Star:

  • Hover ON
    • Star fill changes from WHITE to DARK GREY over 0.2s
    • Star outline changes from GREY to DARK GREY over 0.2s
  • Hover OFF
    • Star fill changes from DARK GREY to WHITE over 0.2s
    • Star outline changes from DARK GREY to GREY over 0.2s
  • Click Toggle ON
    • Star fill changes to/stays RED, ignoring Hover OFF over 0.2s
    • Star outline changes to/stays RED, ignoring Hover OFF over 0.2s

Star Icons - Right of Hovered Star:

  • Hover ON
    • Star fill changes to WHITE over 0.2s
    • Star outline changes to GREY over 0.2s
  • Hover OFF - No Star to Right Selected
    • N/A
  • Hover OFF - Any Star to Right Selected
    • Star fill changes to RED over 0.2s
    • Star outline changes to RED over 0.2s
  • Click Toggle ON
    • Star fill stays WHITE, ignoring Hover OFF
    • Star outline stays GREY, ignoring Hover OFF
